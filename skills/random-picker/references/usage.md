# 详细用法与排错

## 名单是怎么被认出来的

导入后要拿到一个「姓名」列表，规则按优先级依次尝试：

**1. 找表头行。** 在前 12 行里找内容等于 `姓名` / `名字` / `学生姓名` / `名称` /
`名单` / `name` / `fullname` 的单元格。找到就取该列下面的值。

> 会收集该行里**所有**姓名列，不是只取第一个。有的名单把班级排成左右两块
> （`学号|姓名|性别|… | 学号|姓名|性别|…`），表头重复出现两次，只取第一列会
> 静默漏掉一半人。

**2. 没有表头就逐列打分。** 打分依据：

- 表头命中「姓名」类词 `+100`，命中「学号/性别/专业/电话/备注」类词 `-100`
- 列里像姓名的比例（`0~50` 分）
- 列的去重比例（`0~15` 分）——「专业」列会大量重复，姓名列基本不重复

平分时取更靠左的列（姓名一般排在专业、电话前面）。

**什么算「像姓名」：** 2–6 个汉字（允许少数民族姓名的间隔号 `·`），或者英文名。
纯数字（学号、电话）不算，`男`/`女` 这种单个字也不算。

**如果是纯文本列表**（`.txt`，或没有多列的 `.csv`），就整份当名单：按换行、
逗号、中文逗号、顿号、分号、竖线、Tab 切分，并自动去掉 `1. ` `12、` 这类编号前缀。

## 文件格式

| 格式 | 说明 |
|---|---|
| `.txt` | 一行一个名字，也可以逗号／顿号／空格分隔 |
| `.csv` | 有表头就按表头取列，没有就按打分取列；带引号的字段能正确解析 |
| `.xlsx` | 取第一张工作表，走上面同一套列识别规则 |

不支持：旧版 `.xls`、加密的 xlsx、ZIP64 的 xlsx。前两种在 Excel/WPS 里
「另存为」成 `.xlsx` 或 `.csv` 即可。

## 排错

### 打开后中文全是乱码

浏览器导入时按这个顺序试编码，一般不会乱：

1. UTF-8 BOM（`EF BB BF`）→ 剥掉 BOM 按 UTF-8 解
2. UTF-16 BOM（`FF FE` / `FE FF`）→ 按 UTF-16 解（Excel 的「Unicode 文本」导出就是这个）
3. UTF-8（**严格模式**，遇到非法字节就报错）
4. GBK（WPS、Windows 导出的中文 CSV 常见）

第 3 步必须用严格模式，否则非法字节会被静默替换成 `�`，就永远轮不到 GBK 了
——那正是「乱码但不报错」的来源。

如果还是乱码，用记事本打开名单「另存为」并选 UTF-8 编码。

### xlsx 导入失败 / 读出来是空的

浏览器端的 xlsx 解析（`web/xlsx-lite.js`）是尽力而为的实现。它覆盖了共享字符串、
`inlineStr`、富文本 run、stored/deflate、稀疏单元格这些常见情况，但**不覆盖
ZIP64 和加密文件**。

最稳的办法是让 Python 侧来读：

```bash
python scripts/launch.py --roster "名单.xlsx"
```

Python 的 `zipfile` 会自动处理这些边角情况。仍然失败的话，在 Excel/WPS 里
「另存为 CSV」，再拖进页面。

### 列识别错了（比如把「专业」当成姓名）

直接点页面上的「粘贴 / 编辑」，把名单改成一行一个名字保存。这一份名单会覆盖
导入的结果，之后按空格抽取即可。

### 刷新后进度没了

页面状态以内存为准，`localStorage` 只是「能存就存」。用 `file://` 直接打开时，
页面的 origin 是 opaque（`null`），浏览器不保证持久化。

刷新只会回到**名单还在、已抽记录清空**的状态，重新抽即可。

### 页面打开了但一片空白

用浏览器开发者工具看 Console：

- `Failed to load resource ... preload.js` → 正常，说明没有预载名单，忽略即可
- 其他报错请带上截图提 issue

### `python3` 没有反应

Windows 上 `python3` 常常指向微软商店的跳转桩，在非交互 shell 里静默退出。
换成 `python`。确认可用：

```bash
python -V
```

### Claude Code 里说「随机点个名」但技能没被调用

`~/.claude/skills/` 如果是这次新建的顶层目录，需要 `/reload-skills` 或重启
Claude Code 才会加载。也可以用 `/random-picker` 直接点名调用。
